# Library Scrapping · competencia de productos Sip

Anuncios activos de la competencia en Meta Ad Library (Perú), agrupados por producto de Sip:
Crédito Efectivo, Maxicash, Tarjeta de Crédito, Sip con Garantía y DLP (préstamo de libre disposición).

- `index.html`: dashboard con una pestaña por producto.
- `data.js`: anuncios clasificados (anunciante, fecha de inicio, texto, link al anuncio).
- `img/`: miniaturas propias (los links de imagen de Meta caducan).
- `data_raw.json`: captura completa, antes de clasificar.

Captura: 5 nov 2026.
